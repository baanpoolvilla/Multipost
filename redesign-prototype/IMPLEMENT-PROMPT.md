# PROMPT — รีดีไซน์ UI ระบบ Multi-Post (ธีม EasyBoss)

> ใช้ไฟล์นี้เป็นบรีฟ/พรอมป์สำหรับสั่งงาน (คน หรือ AI) ให้ลงมือแก้ UI จริง
> อ้างอิงตัวอย่างหน้าจอ: `redesign-prototype/easyboss-multipost-v3.html`

---

## ⛔ ข้อห้ามสำคัญ — อ่านก่อนเริ่ม

1. **ห้ามแก้ทับ branch `main` เด็ดขาด** — `main` คือตัวที่ deploy และใช้งานจริงอยู่ (production) การแก้ทับอาจทำให้ระบบล่ม
2. ให้ **สร้าง branch ใหม่** ก่อนเสมอ เช่น:
   ```bash
   git checkout main
   git pull
   git checkout -b redesign/ui-easyboss
   ```
3. ทำงานและทดสอบบน branch นี้จนมั่นใจ แล้วค่อยเปิด Pull Request ให้รีวิว **ก่อน** merge เข้า main
4. **ห้ามแตะ logic / routes / services / controllers** ที่ทำงานอยู่ — งานนี้แก้เฉพาะ **ชั้นแสดงผล** (`views/*.ejs`, `public/css/style.css`, `public/js/*`) เท่านั้น
5. อย่าลบหน้าเก่าทิ้งทันที — ให้ทำหน้าใหม่คู่ขนาน/redirect ไว้ก่อน เผื่อ rollback ได้
6. ทดสอบทุกหน้าบน local (`npm run dev`) และเช็คว่า login / โพสจริง / คิว / Agent ยังทำงานครบก่อน merge

## บริบทระบบ

Multi-Post System (Express + EJS, deploy บน Vercel) โพส Facebook แบบส่งหลายที่พร้อมกัน แบ่งงานเป็น **2 ฝั่ง**:
- **โพสลงเพจ** — โพสตรงผ่าน API
- **โพส & แชร์ ลงกลุ่ม** — ต้องใช้ **Desktop Agent** (โปรแกรม Electron บนเครื่อง Windows) รับงานไปโพส

ธุรกิจ: ให้เช่าพูลวิลล่า/ที่พัก (BaanPoolVilla) — ใช้รูปเยอะ โพสลิสต์เดิมซ้ำบ่อย

โมดูลนี้อยู่ในหมวด **Marketing** ของ shell EasyBoss → accent สีส้ม

## 2) โครง Navigation ใหม่ (13 หน้า — คง 2 ฝั่ง)

เปลี่ยน navbar บน → **sidebar ซ้าย** แบ่ง 3 กลุ่ม (ทำเป็น partial `views/partials/sidebar.ejs` ใช้ร่วมทุกหน้า):

**โพสลงเพจ** (accent ส้ม)
- โพสใหม่ · คิว & ปฏิทิน · จัดการเพจ · ภาพรวม · ประวัติ

**โพส & แชร์ ลงกลุ่ม** (accent เขียวอมฟ้า)
- Desktop Agent · โพส/แชร์กลุ่ม · จัดการกลุ่ม · คิวโพสกลุ่ม · ภาพรวมกลุ่ม · ประวัติกลุ่ม

**ระบบ**
- ทีมงาน · คู่มือ / ช่วยเหลือ

### หน้าเดิม → รวมเข้าที่ไหน (ยุบเฉพาะในฝั่งเดียวกัน ไม่ข้ามฝั่ง)
| หน้าเดิม | ปลายทาง |
|---|---|
| overview + page-summary + page-activity | รวมเป็น **ภาพรวม** (มีตัวเลือกช่วงเวลา วันนี้…ทั้งหมด ในหน้าเดียว) |
| history + result | รวมเป็น **ประวัติ** (คลิกแถว → กางรายงานผลรายเพจแบบ drill-down) |
| group-overview + group-summary | รวมเป็น **ภาพรวมกลุ่ม** |
| group-history + group-result | รวมเป็น **ประวัติกลุ่ม** (drill-down รายกลุ่ม) |
| post-queue / job-queue | คงไว้แยกฝั่ง (คิว & ปฏิทิน / คิวโพสกลุ่ม) เพิ่มสลับมุมมองปฏิทิน↔รายการ |
| manage-staff + user-activity + user-activity-detail + audit-log | รวมเป็น **ทีมงาน** (แท็บ สมาชิก / กิจกรรม / Audit log) |
| schedule-post / schedule-center | ยุบการตั้งเวลาให้เป็นตัวเลือกในหน้า "โพสใหม่" |

> คงหน้า **Desktop Agent** ไว้เหมือนเดิม (ปุ่มดาวน์โหลด + สถานะ online/runner/db + ขั้นตอนติดตั้ง) · คง **หมวดกลุ่ม + ประเภท Public/Private/เสียตัง** ตามของจริง

## 3) ฟีเจอร์ที่ต้องเพิ่ม (ทำชุดนี้ก่อน — คุ้มสุด)

1. **คลังรูป (Media library)** — เก็บรูปวิลล่าไว้เลือกใช้ซ้ำ ไม่ต้องอัปทุกครั้ง · ต่อกับ `services/imageStore.js` ที่มีอยู่แล้ว
2. **AI ช่วยเขียนแคปชัน + แฮชแท็ก** — ปุ่มดาว (sparkles) ในหน้าเขียนโพส ให้กดแล้วสร้างข้อความ/แฮชแท็กให้
3. **เทมเพลตโพส** — บันทึกโพสประจำไว้กดใช้ซ้ำ · ต่อกับ `services/templateStore.js` ที่มีอยู่แล้ว
4. **แจ้งเตือนงานพัง + Agent ออฟไลน์** — ส่งเข้า LINE/อีเมล เมื่อโพสล้มเหลว (เช่นโทเคนหมดอายุ) หรือ Agent หลุดกลางงาน
5. **ทำซ้ำจากประวัติ** — ปุ่ม "โพสซ้ำ" ในหน้าประวัติ/รายงานผล เอาลิสต์เดิมมาโพสใหม่ได้ทันที

(ชุดถัดไปค่อยทำ: อนุมัติก่อนโพส, แนะนำเวลาโพส, หน้าแรก Dashboard รวม 2 ฝั่ง, dark mode, นำเข้า CSV)

---

## 4) ลำดับลงมือ (แบบค่อยเป็นค่อยไป)

1. สร้าง branch `redesign/ui-easyboss`
2. ใส่ design tokens + สร้าง `partials/sidebar.ejs`
3. รีสไตล์ทีละหน้า เริ่มจากที่ใช้บ่อยสุด: **โพสใหม่ → คิว & ปฏิทิน → ประวัติ → ภาพรวม** แล้วค่อยฝั่งกลุ่ม แล้วระบบ
4. เพิ่มฟีเจอร์ชุดข้อ 3 (คลังรูป, AI, เทมเพลต, แจ้งเตือน, โพสซ้ำ)
5. ทดสอบครบทุกหน้า + flow จริง (login/โพส/คิว/Agent) บน local
6. เปิด PR ให้รีวิว → merge เข้า main เมื่อผ่าน
